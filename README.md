# 🌾 KisanDB – Farmer Land & Crop Management System

## 📌 Project Overview
KisanDB is a DBMS-based web application designed to manage farmers, their land holdings, crop records, and subsidy eligibility.  
It demonstrates real-world database concepts like normalization, relationships, triggers, procedures, and full-stack integration.

---

## 🚀 Features

- 👨‍🌾 Farmer Registration & Management
- 🗺️ Land Parcel Tracking
- 🌱 Crop Records Management
- 🤝 Joint Land Ownership Handling
- 💰 Subsidy Eligibility System
- 📊 Dashboard with Data Visualization
- 🧠 SQL Console for Query Execution

---

## 🛠️ Tech Stack

### Frontend
- HTML5, CSS3, JavaScript
- Chart.js (for visualization)

### Backend
- Node.js
- Express.js
- MySQL (mysql2)

### Database Concepts Used
- ER Model
- Normalization
- Foreign Keys
- Joins
- Views
- Triggers
- Stored Procedures
- Transactions (ACID properties)
